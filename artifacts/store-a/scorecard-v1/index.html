Where they differ

Brand, category and attribute queries are a retrieval ceiling, not a ranking contest: every matching vendor or product_type has the same grade, so nDCG@10 is 1.000 for any system that fills ten slots with relevant items. The comparison lives in the other strata.

  • Swedish compounds: BM25+Compound 1.000 · native 0.976 · BM25 0.784. Splitting fashion heads (jacka from bomberjacka) is the mechanism.
  • Misspellings: native 1.000 · both BM25 systems 0.645. The storefront corrects typos; this retriever does not.
  • Natural language: BM25+Compound 0.793 · native 0.747 · BM25 0.187.
  • Absent queries (iphone, lego, skidpjäxor): native returned 25 products. Both BM25 systems returned none, because those tokens are missing from the catalog — not because of a fitted abstention model.

Methodology

This is a measurement, not a demo. The catalog was ingested from the public Shopify products.json endpoint, crawled twice, and discarded unless both crawls agreed. Image URLs are stored; images are never downloaded or shown.

Queries. 24 queries, frozen in artifacts/queries/store-a-v1.json before any ranking was computed. They are stratified (brand, category, Swedish compounds, attributes, English equivalents, misspellings, natural language, absent). They were chosen from shopper vocabulary and from catalog structure — vendors, product types, tags — not from looking at anyone’s result lists.

Relevance is catalog-grounded, not human-pooled. A brand query is grade 3 iff vendor matches. A category query is grade 3 iff product_type matches. Compound queries such as jacka treat Jackor as 3 and related outerwear as 2. Absent queries have no relevant documents. This is simple graded relevance: objective, reproducible, and weaker than the human pooled judgements in the full design. It is also not a BM25-shaped judge — a lexical overlap scorer would have rigged the comparison.

Systems. Native is the shopper-facing /search?q=&type=product page, captured once and replayed. Rank comes from the _pos parameter on product links; first page, 20 results. Native is a live black box: its index can disagree with our snapshot, so unmapped handles are counted rather than guessed. BM25 is fielded Okapi BM25 (k1=1.2, b=0.75) over title, vendor, product type, tags, and description. BM25+Compound adds splitting of known Swedish fashion heads (jacka from bomberjacka, jackor → jacka). No embeddings, no reranker, no truncation. Parameters were fixed in advance; nothing was tuned on these queries.

Metric. nDCG@10 with gain 2^rel − 1. IDCG uses the full relevant set, not only retrieved documents. Mean nDCG on the 21 answerable queries is the headline; absent queries cannot be seen by nDCG (padding with grade-0 documents still scores 0), so we also report how many results each system returned on them. P@10 counts grade ≥ 2.

What this number is not. It is not the human-labeled, sealed test split in the design spec. The builder chose the query set. We specialised a lexical retriever for this catalog’s language; the storefront did not. Exact snapshot equality with native search cannot be proven. On this run every captured native handle was in the snapshot (445 mapped, 0 missing). The crawl itself is not republished (the catalog is theirs); the scorecard is auditable from the retained private snapshot and the committed query file, runs, and grades. The retailer is not named here: this page is a methodology demonstration, not a brand audit.
